# Cortado — site integrado

Site aprovado de apresentação do Painel Cortado e Servido, com integração TikTok, privacidade e termos.

Publicado em https://joaoppk2.github.io/cortado-site/ por GitHub Pages, branch main, raiz.

Base visual: painel-cortadoeservido. Documentos de origem: cortadoeservido. Os repositórios anteriores e as URLs OAuth e de verificação TikTok permanecem preservados.

HTML/CSS/JavaScript estáticos, sem build. O código e as credenciais do aplicativo não fazem parte deste site.
